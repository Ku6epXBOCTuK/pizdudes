# Бэклог

## Атлас имён вместо `Text`

Каждому повару своё имя = своя текстура = не батчится, draw call'ов на каждого
повара. Собрать все имена в один атлас, рисовать спрайтами. Инкрементально, без
перепаковки, в атлас только реально отрисованные имена. Минусы: длинные ники
обрезать, обводку `stroke` (у `BitmapText` её нет) рисовать вручную. Сначала
замерить `!статс` — если узкое место в обходе ECS, атлас не поможет.
