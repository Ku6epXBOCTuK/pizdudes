# Pizdudes

Интерактивный виджет для Twitch-стрима: кухня, в которой повара — это зрители
чата. Каждый написавший в чат получает своего повара на экране, и дальше он
готовит заказы: ходит по кухне, берёт ингредиенты со станций, собирает блюда и
относит их на кассу.

Виджет рассчитан на добавление в OBS как браузерный источник.

Посмотреть в работе пока можно на стриме:
[https://www.twitch.tv/ku6epxboctuk](https://www.twitch.tv/ku6epxboctuk)

## Как играть из чата

Напиши что-нибудь в чат — на кухне появится твой повар. Дальше им можно
управлять командами:

- `!заказ` — взять заказ на выдаче;
- `!взять <ингредиент>` — взять сырьё с полки (например, `!взять помидор`);
- `!резать` / `!жарить` / `!варить` / `!месить` / `!печь` — подготовить то, что
  в руках, на нужной станции;
- `!положи` — добавить несомое в заказ;
- `!выкинь` — выбросить то, что в руках;
- `!отдать` — довести заказ до готового блюда и отнести на кассу.

Без команд твой повар просто слоняется по кухне — готовить сам он не будет.
Самостоятельно работает только бот-хозяин кухни.
